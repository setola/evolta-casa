# Evolta Casa

> **In sviluppo — pre-release.** La prima versione funzionante non è ancora stata rilasciata.

Il branch predefinito `develop` contiene il lavoro in corso. Non rappresenta una versione stabile né un rilascio pronto per la produzione.

## Sviluppo locale

Prerequisito: Node.js >= 20.

```sh
npm ci
npm run dev
```

## Verifiche e build

```sh
npm test
npm run build
```

Le chiavi API eventualmente necessarie vanno configurate localmente tramite variabili d'ambiente; non devono essere committate.
